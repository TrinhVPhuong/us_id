# Công Nghệ Sử Dụng

## Frontend

- **Vue 3**: Framework JavaScript để xây dựng giao diện người dùng.
- **Pinia**: Quản lý trạng thái ứng dụng.
- **Vue Router**: Quản lý điều hướng trong ứng dụng.
- **Vite**: Công cụ build nhanh và hiện đại.

## CSS Framework

- **TailwindCSS**: Framework CSS tiện lợi để xây dựng giao diện.
- **DaisyUI**: Thư viện giao diện người dùng dựa trên TailwindCSS.

## Công Cụ Phát Triển

- **TypeScript**: Ngôn ngữ lập trình mở rộng từ JavaScript.
- **ESLint**: Công cụ phân tích mã nguồn để đảm bảo chất lượng code.
- **Prettier**: Công cụ định dạng mã nguồn.
- **@tailwindcss/vite**: Plugin tích hợp TailwindCSS với Vite.
